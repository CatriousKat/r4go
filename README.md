# r4go
An experimental RAR 4 creator written in Golang. <br>
DISCLAIMER: r4go is an independent, clean-room utility and is not affiliated with, authorized, or endorsed by RARLab. It is an experimental project utilizing only uncompressed storage methods and is not intended for production use. <br>
<br>
Usage: <br>
``go run . -o <output.rar> [folder/file1.txt] [folder2/file2.txt]`` OR
`` r4go -o <output.rar> [folder/file1.txt] [folder2/file2.txt]``
